# Metal Prod Service

Public website for **Metal Prod Service S.R.L.** (Satu Mare) — CNC machining, prototyping, series production and in-house heat treatment.

## Live site (free GitHub Pages)

**https://trifmarius1.github.io/MetalProdService/**

The site is rebuilt and published automatically on every push to `main`.

## Local development

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173/`).

```bash
npm run build
npm run preview
```

## Tests

```bash
npm test
npm run test:e2e
npm run test:load
```
